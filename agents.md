# Vigia Digital

## O que é este projeto
Landing page e sistema de segurança digital via WhatsApp.
O produto analisa mensagens, prints e boletos suspeitos
e responde com análise de risco em linguagem simples.

## Público-alvo
Brasileiros comuns, incluindo pessoas mais velhas.
Linguagem sempre simples, acessível, sem jargão técnico.

## Stack permitida
HTML, CSS, JavaScript puro (sem frameworks).
Sem dependências externas além de Google Fonts.

## Estilo visual
Sério, confiável, moderno. Cores: azul escuro, branco, 
toques de vermelho para alertas. Sem poluição visual.

## Idioma
Sempre português brasileiro.
